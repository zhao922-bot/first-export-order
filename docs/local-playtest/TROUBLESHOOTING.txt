《出海第一单》故障排查

1. 双击后出现“Runtime missing”或文件不存在
   请先“全部解压”整个 ZIP，保持 runtime/node.exe、server.mjs 和 web/ 同级。
   不要只复制启动脚本，不要在 ZIP 内直接运行。试用普通本地目录而非网络盘。
   若设备管理策略或安全软件禁止运行，请联系主持人/设备管理员核对来源与
   ZIP 摘要，不要关闭安全软件或绕过组织策略。此包没有安装步骤。

2. 显示“文件校验失败/大小不符”
   保留报错中的文件名，重新下载并解压到新目录。不要手改 manifest 绕过校验。
   ZIP 同目录提供 .zip.sha256 摘要；组织者可用 Get-FileHash 核对。
   package-manifest 用来检测缺件/损坏，不是第三方签名或防篡改认证。

3. 端口 4173 已被占用，或重复双击又出现一个窗口
   先查看是不是已经有试玩启动窗口；回到原浏览器继续即可。
   切换本机/手机模式需先关闭原启动窗口。程序不会抢占端口、自动换端口、
   自动结束其他进程。不要结束你不认识的服务。
   如确需由主持人更换端口，在解压目录的终端运行：
     .\START-LOCAL.cmd --port=4180
   或：
     .\START-PHONE.cmd --port=4180
   变更端口会换存储域，先导出原地址的经营存档和指标；整轮保持固定端口。

4. 没有自动打开浏览器 / 页面空白
   将窗口显示的完整 http:// 地址粘贴到最新版 Chrome、Edge 或 Safari。
   不用搜索框搜索，不将 http 改成 https，不使用 file:// 或直接打开 index.html。
   确认窗口显示 READY 且仍在运行。若仍空白，记录浏览器版本和错误截图交给主持人。

5. 手机访问不到
   a. 必须使用 START-PHONE.cmd；START-LOCAL.cmd 只允许电脑本机。
   b. 电脑手机连接同一网络，手机地址应为电脑的私有 IPv4 + 相同端口。
      localhost/127.0.0.1 指手机自己，0.0.0.0 也不是手机访问地址。
   c. 先在电脑浏览器打开同一个局域网地址；确认电脑没有休眠，服务窗口未关闭。
   d. 若有多张网卡，选择实际 Wi-Fi/网线网卡。VPN/代理或虚拟网卡可能影响路径；
      按所在网络政策检查设置，勿使用公网隧道或路由器端口映射。
   e. 在受信任的专用网络允许包内 node.exe 的防火墙访问，勿整体关闭防火墙。
   f. 访客 Wi-Fi、公司 AP 隔离或手机与电脑不在同一子网可能禁止互访。
      请让主持人使用允许设备互访的测试网络；本包不会自动修改这些设置。
   g. 显示“未找到私有 IPv4 网卡”时先连接网络，再重启手机模式。
      当前包只提供 IPv4 私有局域网访问，不提供公网或纯 IPv6 接入。

6. 原存档看不到 / 手机和电脑进度不一样
   检查设备、浏览器、协议、IP/域名和端口是否与原来完全相同。
   原来用 localhost、5173 或其他 IP 时，新地址不会读取旧地址的浏览器存储。
   先回到原地址查看并导出，不要先新开局或清理浏览器数据。
   无痕窗口关闭后记录可能消失；试玩期间不要清理网站数据。
   跨设备只能主动导入经营存档，不能自动迁移本地试玩统计或合并账户。

7. 下载按钮点了但没找到 JSON
   查看当前设备浏览器的下载记录；手机 Safari 通常在“文件/下载”中。
   使用浏览器自带下载/存储到文件操作。不要把“经营存档”当成“试玩指标”。
   如出现存储失败，请在当前页尽快导出后交回，不关闭或刷新来碰运气。

8. 怎样停止、卸载和再次开始
   Ctrl+C 或关闭启动窗口即停止服务；不安装后台服务，不改系统 PATH。
   再次双击同一启动脚本，使用同一地址即可继续。删除解压目录可移除程序，
   浏览器内存档仍单独存在；如需清理，先导出并按主持人约定处理。

向主持人报告：匿名编号、操作时间、电脑/手机与浏览器版本、使用的启动入口、
端口、完整报错及是否已经导出；截图遮盖私人信息。请勿提供真实贸易单据。
