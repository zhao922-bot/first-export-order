《出海第一单》本地试玩包

适用：Windows 10/11 x64 电脑；手机使用浏览器访问电脑提供的局域网地址。
包内已带生产网页和 Node.js 运行时，无需安装 Node、pnpm 或工程依赖。
Mac、Linux、Windows ARM 原生运行不在这个发行包的验收范围。

【电脑：解压后双击一次启动】
1. 右键 ZIP → 全部解压到一个普通本地文件夹，例如桌面上的“出海试玩”。
   不要直接在压缩软件里运行，也不要双击 web/index.html。
2. 双击 START-LOCAL.cmd。程序校验包内文件后自动打开浏览器。
   如未自动打开，复制启动窗口显示的 http://127.0.0.1:4173/#/ 。
3. 保留启动窗口。首页按主持人的安排选择“前测并开始七关试玩”。
4. 结束时先完成后测并主动导出试玩指标，再关闭启动窗口或按 Ctrl+C。

【手机：与电脑连接同一 Wi-Fi/局域网】
1. 如果已经启动本机模式，先关闭那个启动窗口，再双击 START-PHONE.cmd。
2. 电脑和手机接入同一个受信任的网络，电脑保持唤醒。
3. 启动窗口会显示网卡名与地址，例如：
   以太网: http://192.168.1.3:4173/#/
   这是示例，请使用你自己窗口显示的地址；优先实际 Wi-Fi/网线网卡，
   不要选择 VMware、Virtual、VPN 等虚拟网卡。
4. 把地址完整输入手机的 Chrome、Safari 或 Edge 地址栏。
   手机不要输入 127.0.0.1、localhost 或 0.0.0.0。
5. Windows 如提示网络访问权限，只在你信任的专用网络允许此包内 node.exe。
   程序不会自动修改防火墙、不需要安装服务，也不配置公网映射。

【存档和试玩记录】
每台设备、每个浏览器分别保存自己的进度，电脑不会收到手机的存档或答案。
恢复时使用原设备、原浏览器、原 URL（包含协议、IP/域名和端口）。
localhost、127.0.0.1 和局域网 IP 是不同地址，会对应不同的浏览器存储。
电脑换网络导致 IP 改变，手机也会看到另一个存储域；尽量在同一网络完成。
如果之前是在 5173 开发地址试玩，4173 不会自动出现原进度：先从原地址导出
经营存档和指标。经营存档可按游戏内导入流程继续，但指标不跨浏览器合并。
新一轮 12 人首局应使用主持人指定的新浏览器配置，不覆盖以前的记录。

手机刷新不会重新抽签或重复付款。不要用无痕模式、清除网站数据或重复开局
来“恢复”。存档失败提示出现时先导出，不要反复刷新。
手机上的 JSON 下载保存到手机“下载/文件”位置，不会自动传到电脑；请按
主持人的说明主动交回。经营存档 JSON 和试玩指标 JSON 不是同一种文件。

【随包资料】
PLAYER_GUIDE.txt：无答案试玩指引。
FEEDBACK_FORM.txt：可复制填写的反馈表。
TROUBLESHOOTING.txt：端口、浏览器、手机连接、文件缺失和存档问题。
package-manifest.json：版本及文件摘要，供组织者核对。
THIRD-PARTY-NOTICES.txt、runtime/LICENSE：第三方许可原文。

本机模式解压后可离线运行；手机模式需要局域网，但不需要互联网。
此包只用于本地教学试玩，没有公开部署、云存档、排行榜或自动上传功能。
