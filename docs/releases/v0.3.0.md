## 安装与更新

Windows 10/11 x64：下载 EXE，关闭旧版后双击运行，无需安装开发工具。沿用 `%APPDATA%\FirstExportOrder`，移动 EXE 不会删除进度。

Android 7.0+：下载 APK，按系统提示直接覆盖更新；包名和原测试签名相同，versionCode 为 3。更新前在旧版“存档与恢复”导出当前进度并确认备份已保存；不要卸载或清除数据。EXE 没有商业代码签名，APK 使用测试签名，尚未上架商店。

各端可离线游玩，存档互不自动同步。跨设备迁移用 JSON 导出/导入。详细步骤与故障排查见 [原生试玩说明](../NATIVE_PLAYTEST.md)，Release 附同版说明和校验清单。

## 验证记录

本轮单元测试 654/654，11 个核心公式模块覆盖率四项均为 100%，JSON / TypeScript / Vite 构建、ESLint 和 Prettier 通过。Windows 原生回归 5/5，通过实际免安装 EXE、离线七关、0.1.0 / 0.2.0 升级、JSON 导入导出和进程重启。安装包内 30 项运行资源与生产构建逐文件 SHA-256 一致（Windows 另含构建 manifest），Android 签名与公开 0.2.0 相同。

Android 回归覆盖旧版备份及重启确认、两个历史版本的覆盖升级、离线七关、系统文件选择器保存/取消、返回键和进程重启。最终统计与完整复测历史见随 Release 提供的 [TEST_RESULTS.json](https://github.com/zhao922-bot/first-export-order/releases/download/v0.3.0/TEST_RESULTS.json)。

安卓首轮两项升级检查在刚输入后直接强制停止旧进程，发现末次草稿回退；独立诊断在未安装新版的 0.2.0 上也复现，确认不是升级迁移导致。正式回归按照使用说明先导出备份、核对文件并重启旧版确认存档，再覆盖安装新版。测试不承诺强杀进程或断电瞬间的写入持久性。随后两次复测遇到测试机资源不足、ADB/模拟器退出而中断，已限制覆盖率并发、回收长期运行的本项目预览进程并独立重跑；历史失败日志保留在本地证据目录。
