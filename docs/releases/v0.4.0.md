# 0.4.0 固定界面试玩版

本版将七关经营工作台改为手机竖屏、Windows 横屏的固定分区。顶部实时显示现金、已确认利润、信誉、客户信任和游戏日，发生变化时短暂显示增减。长内容通过翻页查看，资料和决策记录分别切换，表单翻页保留输入。

新决策不再反复进入独立后果页；林姐复盘、纠错、事件和救援继续保留。旧存档如果正停在后果页，先显示原反馈，由玩家点“接着处理”继续。布局与提示仍由 JSON 驱动，不改变七关经济参数和存档格式。

## 安装与升级

- Windows 10/11 x64：下载 `FirstExportOrder-0.4.0-win-x64.exe`，退出旧版后双击新版。沿用 `%APPDATA%\FirstExportOrder` 和 `trade://app/`，无需 Node.js。
- Android 7.0+：下载 `FirstExportOrder-0.4.0-android-test.apk`，直接覆盖安装。包名仍为 `cn.firstexportorder.game`，versionCode 为 4，与此前分发版本使用相同测试签名。
- 更新前在旧版“存档与恢复”导出进度并确认文件已保存。安卓不要先卸载或清除数据；Windows 旧进程未退出时新文件只会激活旧窗口。
- 首次运行、七关剧情和角色资源都支持离线。浏览器、EXE、APK 各自保存，需要跨端迁移时使用 JSON 导入/导出。

完整操作与排障见 [原生试玩说明](../NATIVE_PLAYTEST.md)。下载入口为 [v0.4.0 Release](https://github.com/zhao922-bot/first-export-order/releases/tag/v0.4.0)。源码、默认分支和版本标签同步，避免安装包已更新而首页仍指向旧版。

## 本轮原生检查重点

真实旧版 0.1.0、0.2.0、0.3.0 各自产生进度后升级，核对账本、现金、RNG、报价草稿、引导状态和动效偏好。Windows 另外检查原始便携 EXE 自解压、离线七关、导出/导入和重启；Android 检查真实覆盖安装、离线七关、系统保存/取消、返回键、进程重启、固定分页和真实软键盘。

原生截图审查发现 Windows 高显示缩放时可用高度约 557 CSS px，手机短视口规则隐藏角色后仍保留桌面空列。已增加宽屏低高度布局，保留场景和操作列，并补充对应浏览器和原生断言。

常规测试中反复弹出 Node.js 防火墙授权的原因也已修正：临时目录中的 CMD 运行时不再默认启动局域网监听；普通测试使用回环地址并校验 LAN 参数，真实局域网测试须显式启用。未修改系统防火墙规则。详见 [维护者说明](../local-playtest/MAINTAINER.md#回归)。
