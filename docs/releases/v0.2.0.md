完整七关、12 个固定种子事件、结局复盘、新手引导与本地存档；新增林姐和五类客户立绘、七关场景与轻量动效。动画不驱动交易或付款，顶部可关闭动效。

应用版本 `0.2.0`；业务内容 `0.10.0-slice`；引导 `onboarding-1`；演出 `presentation-1`。公开发布整理了 README、截图、忽略规则和 CI 配置，没有修改已验证的业务代码、剧情和打包资源。

## 使用与限制

详见 [安装、升级与排障](../NATIVE_PLAYTEST.md)。EXE 未作商业代码签名，APK 使用测试签名。重建 APK 若换了签名，无法直接覆盖已分发的旧包；密钥不公开。

本项目不把模拟器结果当成所有设备兼容保证。专业文案仍标记待审校，经营参数为教学算例。历史原始测试日志和本地升级输入不提交到公共仓库。
