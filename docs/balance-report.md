JSON 调整：quantityBulk 从 2 改为 1.10，openingC 从 8% 改为 7.5%；新增报价准备费 ¥100 和三次有效数值错误上限。首次错误保留分步复盘，格式错误不计次。两个新 JSON 节点提供真实丢单及林姐复盘，不伪造采购或清空资本。初始现金、事件概率/权重及优秀信誉门槛未按策略改写。

稳妥最低现金 ¥29,059.68；激进最低 ¥5.00。激进另外 120 局在 L05.balance 出现实际资金缺口并按真实退款停止采购，不计入第 4/6/7 关翻车门槛。四结局自然分布：稳妥优秀 1,000；激进保本 10、学费 990；乱选学费 1,000；自然破产均 0，不能据此声称验证了自然破产频率。
