# 《出海第一单》试玩指引

你将模拟完成一笔外贸订单，从选品、找客户、报价、谈判、备货验货、出运到单据与收款。请按自己的判断选择；不需要事先学习外贸，也没有规定的通关路线。金额与业务情境用于教学，不能作为实际交易依据。

## 开始

1. 记下主持人给你的匿名编号和试玩地址，用同一台设备、同一浏览器打开。不要使用无痕模式，同时只保留一个游戏标签页。
2. 首页点“前测并开始七关试玩”，独立回答六道小题；可以跳过，不知道就按自己的理解作答。请不要查答案或请别人代答。
3. 进入游戏后按界面提示完成任务，可以随时查看游戏内知识图鉴。遇到看不懂、操作不顺或不符合直觉的地方，请告诉主持人。
4. 看到林姐复盘或纠错机会时，按自己的判断处理。没有强制要求你选某种方式或触发某个事件。

带新手引导的版本会高亮当前可操作位置，并陪你完成首关操作。高亮不是正确答案，你仍可自由选择。可以跳过，也可随时点击“下一步提示”或“重新查看引导”；重新查看不会重开订单。完成示范后，前台停留较久会给出可关闭的下一步提醒。

## 暂停与恢复

请告诉主持人你停在哪一关。游戏自动保存本浏览器进度，重新打开原地址后按首页继续入口恢复；不要为了恢复而点击开始新局或清理浏览器数据。刷新不会按正常设计重新抽事件或重复付款，如观察到异常请立即记录操作和金额。

如出现保存失败提示，请先导出当前存档和试玩记录，再联系主持人；不要反复刷新。设备、浏览器、地址或端口不同，不能自动共享进度。试玩记录和经营存档是两种不同的 JSON 文件。

## 结束或提前退出

1. 到达结局后点“进行知识后测 / 导出试玩指标”，独立回答另一组六题，也可以跳过。
2. 侧栏进入“试玩记录与知识测评”，下载 `first-export-playtest.json`。提前退出时也可从这里导出，没有后测不会记作零分。
3. 将文件交给主持人，由其按编号重命名；如果之后恢复并继续，请再导出一份，不覆盖早先的原件。
4. 填写反馈表。真实的困难、退出和失败都对改进有帮助，不需要为了得到好结局而反复重开。

记录保存在本浏览器，不自动上传。你可以拒绝导出、跳过测评、中止试玩或向主持人提出撤回。记录含匿名局号、选择与事件标识、各关有效时长、测评选项和结果，不需要姓名、联系方式或真实业务材料。主持人会说明保存期限和使用方式。
